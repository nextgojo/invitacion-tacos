# Invitacion Tacos

Sitio simple para compartir una invitación a tacos.

## Archivos incluidos
- `index.html` — Página principal de la invitación.
- `style.css` — Estilos de la página.
- `script.js` — Pequeña interacción (copiar enlace).
- `README.md` — Este archivo.

## Cómo publicar en GitHub Pages
1. Asegúrate de que los cuatro archivos estén en la raíz del repositorio `nextgojo/invitacion-tacos`.
2. Haz commit y push a la rama `main`:
   ```
   git add .
   git commit -m "Add invitacion tacos site"
   git push origin main
   ```
3. En GitHub, ve a: Settings → Pages
   - Source: Branch: `main`
   - Folder: `/ (root)`
   - Save
4. Espera ~1 minuto y visita:
   `https://nextgojo.github.io/invitacion-tacos/`

## Personaliza
- Cambia la fecha, la hora y el lugar dentro de `index.html`.
- Si quieres un formulario de RSVP en línea o un contador, puedo ayudarte a integrarlo.

¡Disfruta compartiendo la invitación!
